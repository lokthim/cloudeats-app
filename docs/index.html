🍔 CloudEats

A microservices-based food ordering platform built with Node.js, Docker, MySQL, and Redis.

Node.js Docker MySQL Redis GitHub Actions

Architecture

  • User Service — JWT authentication, port 3001
  • Menu Service — Menu CRUD + ratings, port 3002
  • Order Service — Cart + orders via Redis, port 3003

Quick Start

git clone https://github.com/YOUR-USERNAME/cloudeats-app
cd cloudeats-app
cp .env.example .env
docker compose up -d
